# MOCCA

The following pages describe general usage of MOCCA, configuring the tool for a telescope other than the setup at the [Blaauw Observatory](https://www.rug.nl/research/kapteyn/sterrenwacht/), and a summary of the methods used to quantify aperture obstruction:

- [General usage](usage.md)
- [Configuring MOCCA](config.md)
- [Methods to quantify aperture obstruction](methods.md)

If you're interested in the detailed mathematics and models that MOCCA uses to quantify obstruction, please refer to the following resources and the references therein:

- [Mick Veldhuis (2021), Remodeling Dome Control: Applications for the Blaauw Observatory.](https://fse.studenttheses.ub.rug.nl/id/eprint/25172)
- [Mick Veldhuis, Jake Noel-Storr (2021), PracticalAstronomyCrew/telescope-models: Aperture Obstruction Models (Version v1.1).](https://doi.org/10.5281/zenodo.5086375)
